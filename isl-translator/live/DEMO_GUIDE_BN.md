# ডেমো চালানোর নির্দেশিকা (হ্যাকাথন)

## ১. ডেমো চালু করা

ওয়েবসাইট এখন **React (frontend) + FastAPI (backend)**। প্রথমবার একবারই বিল্ড করতে হবে:

```bash
cd "D:\new Sign language\isl-translator\frontend" && npm install && npm run build
```

তারপর প্রতিবার ডেমোর সময় শুধু এই কমান্ডটি:

```bash
cd "D:\new Sign language\isl-translator\backend" && "D:\new Sign language\INCLUDE\venv\Scripts\python.exe" app.py
```

তারপর ব্রাউজারে খুলুন: **http://127.0.0.1:8000**

পর্দায় যা থাকবে:
- বাঁ দিকে ক্যামেরা ("Start camera" চাপুন)
- ডান দিকে চেনা সাইন আর ইংরেজি বাক্য
- নিচে ডাক্তারের উত্তর লেখার ঘর (রোগীর জন্য বড় করে দেখাবে + পড়ে শোনাবে)
- উপরে ডানদিকে **"Learn the signs →"** লিংক

## ১ক. সাইন শেখার পেজ (যে কেউ ব্যবহার করতে পারবে)

**http://127.0.0.1:8000/learn**

- ৩৭টি সাইনের আসল ভিডিও আছে, ছবিতে ক্লিক করলেই চলবে (বারবার লুপ হবে)
- উপরে খোঁজার ঘর — শব্দ লিখে খুঁজুন
- কোন কোন বাক্য দেখাবেন তার তালিকাও আছে
- ডেমোতে অপরিচিত কেউ এলে তাকে শুধু এই পেজটা খুলে দিন: ভিডিও দেখে নকল করলেই হবে

## ১খ. মঞ্চে ওঠার আগে — সবচেয়ে জরুরি তিনটি কথা

1. **ফ্রেমে যেন একজনই থাকে।** পোজ-ট্র্যাকার একসঙ্গে একজনকেই অনুসরণ করে; পাশে আরেকজন
   দাঁড়ালে সে-ই ধরা পড়তে পারে, আর তখন প্রতিটি সাইনের কনফিডেন্স ২০-৩০%-এ নেমে যায়।
   ক্যামেরার নিচে **"Frame the signer"** সারি আছে — Left / Middle / Right বেছে নিন বা
   zoom স্লাইডার টানুন। এটি ব্রাউজারেই ছবি কেটে পাঠায়, তাই শুধু আপনিই থাকবেন।
2. **মাথা আর দুই হাত পুরো ফ্রেমে রাখুন**, ক্যামেরা থেকে দেড়-দুই হাত দূরে।
3. **প্রতিটি সাইনের পরে হাত এক সেকেন্ড থামান।** থামলেই সাইনটি ধরা হয় এবং বাক্য
   সঙ্গে সঙ্গে বড় হতে থাকে। দেড় সেকেন্ড স্থির থাকলে বাক্য শেষ হয়ে পড়ে শোনানো হয়।
   তাড়াহুড়ো হলে **"Finish sentence"** চাপুন — হাতে ধরা শেষ সাইনটিও যোগ হবে।

## ২. ডেমোর গল্প (মঞ্চে যা বলবেন)

1. **সমস্যা:** ভারতে বধির মানুষ ডাক্তারের কাছে গেলে দোভাষী পান না। জরুরি অবস্থায় এটা বিপজ্জনক।
2. **আমাদের সমাধান:** রোগী সাইন করবে → পর্দায় ইংরেজি বাক্য → ডাক্তার পড়বেন। ডাক্তার টাইপ করবেন → রোগী পড়বেন।
3. **লাইভ দেখান:** ক্যামেরার সামনে সাইন করুন (নিচের তালিকা দেখে)।
4. **সংখ্যা দেখান:** ৫৩টি সাইন চেনে, নিজের ওয়েবক্যামে রেকর্ড করা টেকে **৯২%** সঠিক
   (২৭২টি টেকে মাপা, সম্পূর্ণ লাইভ পাইপলাইনে), ৩% ভুল, ৫% ধরতে পারে না।
   সাইনের মাঝের নড়াচড়া ভুল শব্দ হিসেবে ঢোকে মাত্র ৫% ক্ষেত্রে (আগে ছিল ৫৬%)।
   ফিংগারস্পেল: ৩৭টি অক্ষরের ৩৫টি ঠিক ধরে, ০.৩৫ সেকেন্ডে।
5. **সততা:** কোন শব্দগুলো নেই তা বলুন (pain, fever-এর আলাদা সাইন ISL-এ নেই)।

## ৩. মঞ্চে যেসব বাক্য দেখাবেন

সাইনগুলো শেখার জন্য প্রতিটির আসল ভিডিও আছে `data/videos/<শব্দ>/` ফোল্ডারে — চালিয়ে দেখে নকল করুন।

| যা সাইন করবেন | পর্দায় আসবে |
|---|---|
| HELLO → HOW ARE YOU | Hello, how are you? |
| I → SICK → TODAY | I am sick today. |
| I → HOT | I have a fever. |
| I → HOT → NIGHT | I have a fever at night. |
| I → WEAK → MORNING | I am weak in the morning. |
| I → COLD → NIGHT | I am feeling cold at night. |
| I → MEDICINE | I need medicine. |
| I → BATHROOM | I am going to the bathroom. |
| MOTHER → SICK → YESTERDAY | My mother was sick yesterday. |
| PATIENT → BED → WEAK | The patient is in bed and weak. |
| DOCTOR → HOSPITAL → TOMORROW | The doctor is going to the hospital tomorrow. |
| THANK YOU | Thank you. |

### মডেল যে ৩৭টি সাইন চেনে

alive, bad, bathroom, bed, cold, dead, doctor, family, father, friend, good, he,
healthy, hello, hospital, hot, house, how_are_you, i, medicine, money, morning,
mother, night, old, patient, school, she, sick, strong, thank_you, today, tomorrow,
weak, yesterday, you, young

প্রতিটির আসল ভিডিও `data/videos/<শব্দ>/` ফোল্ডারে আছে — দেখে শিখে নিন।

**নিয়ম:** প্রতিটি সাইনের পরে **হাত নামিয়ে ১ সেকেন্ড থামুন**। থামলেই সিস্টেম বোঝে সাইন শেষ।
২ সেকেন্ড চুপ থাকলে বাক্য তৈরি হয়ে যাবে।

- ল্যাপটপ চার্জে রাখুন, Chrome-এ বেশি ট্যাব খুলবেন না (RAM কম)

## ৬. প্রশ্ন এলে উত্তর

**প্র: কত শব্দ চেনে?**
উ: এখন স্বাস্থ্য খাতের শব্দভাণ্ডার। নতুন শব্দ যোগ করা সহজ — ভিডিও নামিয়ে ১ মিনিটে আবার ট্রেন।

**প্র: ডেটা কোথা থেকে?**
উ: INCLUDE ডেটাসেট (AI4Bharat, CC BY 4.0) — বধির স্কুলের প্রকৃত সাইনারদের ভিডিও।

**প্র: INCLUDE-এর তৈরি মডেল ব্যবহার করলেই তো হতো?**
উ: করেছিলাম, ওয়েবক্যামে কাজ করেনি। কারণ ওটা ফ্রেমের পিক্সেল অবস্থান শেখে। আমরা শরীরের
সাপেক্ষে হিসাব করি, তাই ক্যামেরা বদলালেও কাজ করে। "কিছু করছি না" ক্লাসও যোগ করেছি।

**প্র: বাক্য কে বানায়?**
উ: নিয়ম-ভিত্তিক টেমপ্লেট (ইন্টারনেট ছাড়াই), আর API key দিলে LLM আরও ভালো বাক্য বানায়।

**প্র: এটা কি চিকিৎসায় ব্যবহার করা যাবে?**
উ: না। এটা সহায়ক ডেমো, চিকিৎসা যন্ত্র নয়। প্রকৃত চিকিৎসায় মানুষ দোভাষী লাগবে।
